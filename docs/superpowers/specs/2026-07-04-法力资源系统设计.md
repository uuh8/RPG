# 法力资源系统设计

## 目标

为法师的法术编程系统接入真实 `Mana` 资源：蓝条随时间自动恢复，施法时按当前法杖程序实际执行到的法术扣除 `ManaCost`。当本层施法所需 Mana 不足时，本层施法整体失败，不生成法术，也不扣 Mana。

## 核心语义

1. `Mana` 是恢复型资源，不是一次性弹药。
2. 所有类型的法术都消耗 Mana：`Emit`、`StaticProjectile`、`Modify`、`Multicast` 都读取 `SpellDefinition.ManaCost`。
3. 当前层 Mana 不足时采用方案 A：整层失败，`SpellCaster` 不调用实例化逻辑，`ManaComponent` 不扣值。
4. 当前层 Mana 足够时：先扣除当前层实际执行法术的总 Mana，再运行 `CastEvaluator.Evaluate` 产出 `EmitCommand`。
5. 触发类 payload 不预付费。触发投射物释放时只支付触发投射物本体所在层的成本；payload 在命中或定时触发时作为新层重新检查并扣 Mana。
6. `Modify` 和 `Multicast` 的成本只在它们被解释器读到时发生。触发投射物捕获 suffix 后，本层停止读取，suffix 内法术的成本留到 payload 触发时再算。

## 架构方案

新增 `Game.Combat.ManaComponent`，挂在玩家身上，与 `HealthComponent` 类似负责持有资源状态。它放在 `Game.Combat`，因为 `Game.Character.SpellCaster` 需要扣 Mana，`Game.UI.PlayerManaBar` 需要读取 Mana；二者都可以依赖 `Game.Combat`，不会破坏 asmdef 方向。

`Game.Skills.CastEvaluator` 保持纯逻辑，不引用 `ManaComponent`。它新增 `EstimateManaCost(...)`，用于在 runtime 施法前预估当前层成本。`Evaluate(...)` 仍负责解释法术并产出 `EmitCommand`，同时修正旧的 fizzle 语义，让 `Modify` / `Multicast` 也能消耗 Mana。

`Game.Character.SpellCaster` 从占位 `_availableMana = 9999` 改为引用 `ManaComponent`。`CastWand` 和 payload `RunCast` 都走同一入口：先估算成本，调用 `CanSpend`，成功后 `Spend`，再 Evaluate 并生成投射物。

`Game.UI.PlayerManaBar` 参考 `PlayerHealthBar`，使用 `Image.fillAmount` 每帧平滑显示 `CurrentMana / MaxMana`。蓝条 UI 资源由开发者在 Unity Editor 中拖入。

## 失败与边界

- 未配置 `ManaComponent`：为了避免旧场景直接无法测试，`SpellCaster` 允许施法并输出 `GameLog.Warn`，等价于暂时无限 Mana。
- `MaxMana <= 0`：`ManaComponent` 自动钳制为至少 1，避免除零和永久不可用。
- `ManaCost < 0`：估算和扣费时按 0 处理，防止负成本给玩家回蓝。
- payload 触发时 Mana 不足：payload 层失败，不生成后续法术，不影响已经存在的触发投射物。

## Editor 配置要求

1. 在 `WizardPlayer` 上添加 `ManaComponent`。
2. 设置 `Max Mana`、`Start Full`、`Mana Regen Per Second`。建议初始测试值：`MaxMana = 100`，`ManaRegenPerSecond = 20`，`StartFull = true`。
3. 在 `WizardPlayer` 的 `SpellCaster` 上把 `Mana Component` 字段拖入同物体的 `ManaComponent`。
4. 在 HUD Canvas 下创建或复用蓝条 GameObject，添加 `PlayerManaBar`。
5. 把蓝条填充用的 `Image` 拖入 `PlayerManaBar._fill`，并设置该 `Image` 的 `Type = Filled`、`Fill Method = Horizontal`。
6. 把 `WizardPlayer` 上的 `ManaComponent` 拖入 `PlayerManaBar._playerMana`。
7. Play Mode 验证：低 Mana 不能施法；等待蓝条恢复后能施法；触发类 payload 在触发时才消耗 Mana。
