# 法师敌人法术编程 Implementation Plan

> **For agentic workers:** 按 Task 顺序在当前会话内实施并逐项复核。项目禁止未经本次用户明确授权使用 SubAgent；因此默认使用 `superpowers:executing-plans` Inline Execution。Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把普通远程法师敌人的固定火球生成逻辑替换为开发者 Authoring 的 `WandLoadout` 法术程序，并让多程序精英怪在每次实际释放时随机选择且避免连续重复。

**Architecture:** `RangedEnemyController` 在 Prefab 上保存 `WandLoadout[]` 引用，普通敌人配置 1 项，Prefab Variant 可覆盖为 2～3 项；`Awake` 一次性压缩有效程序，施法释放点调用纯选择器选出下一项，再通过现有 `SpellCaster.CastProgram(..., SpellManaPolicy.IgnoreMana)` 进入统一解释器与投射物 Runtime。`EnemyDefinition` 继续位于 `Game.Combat`，不引用 `Game.Skills`，从而避免 Combat → Skills 的反向依赖。

**Tech Stack:** Unity 6.3、C#、ScriptableObject、Game.Character / Game.Skills / Game.Combat asmdef、NUnit EditMode Tests、Animator `normalizedTime`、`SpellCaster`、`FormerlySerializedAs`。

**Design:** 2026-09-02 当前任务对话中已逐节确认；按项目规则不另建重复 spec，本计划同时承担设计与执行契约。

## Global Constraints

- 仅开发者在 Unity Editor 中 Authoring；不增加玩家 UI、存档或 Runtime 敌人法术编辑。
- 普通法师配置 1 个 `WandLoadout`；多程序敌人均匀随机，并在候选数大于 1 时排除上一次选择。
- Enemy 施法固定使用 `SpellManaPolicy.IgnoreMana`；攻击节奏继续由 `EnemyDefinition.AttackCooldown` 控制。
- `Game.Combat` 不得引用 `Game.Skills`；`WandLoadout[]` 由 `Game.Character.RangedEnemyController` 持有。
- 不复制 `CastEvaluator`、`EmitCommand`、Payload 或 Projectile 逻辑；统一复用 `SpellCaster.CastProgram`。
- 状态对象仍在 `Awake` 预创建；`Update`/攻击热路径禁止 LINQ、闭包、装箱和选择容器分配。
- 删除 `EnemyDefinition.ProjectileSpeed` 与 `EnemyDefinition.ProjectilePrefab`；保留 `AttackDefinition` 的动画状态名和 `ArrowSpawnTime`。
- 不修改当前用户已有 dirty 文件：`WizardPlayer.prefab`、`P7_DemoRun.unity`、`P7_DemoRun/NavMesh-Navigation.asset`、`P8_BossField.unity`。
- 不手工创建 Unity `.meta`；新增 ScriptableObject 资产由 Unity Editor 创建并生成 GUID。
- 只把静态审查、EditMode、PlayMode、Scene Playthrough、Profiler 各自能够证明的内容写成对应证据，不越界声称。

```csharp
namespace Game.Character
{
    /// <summary>
    /// 把外部随机样本映射为 Enemy 下一套法术程序索引。无可变状态、无 Scene 查询，
    /// 因此随机来源与选择规则可以分别验证；多候选时用紧凑索引映射排除上次选择。
    /// </summary>
    public static class EnemySpellProgramSelector
    {
        public static int SelectNextIndex(int programCount, int previousIndex, float sample01)
        {
            if (programCount <= 0) return -1;
            if (programCount == 1) return 0;

            float sample = SanitizeSample(sample01);
            bool hasValidPrevious = previousIndex >= 0 && previousIndex < programCount;
            int candidateCount = hasValidPrevious ? programCount - 1 : programCount;
            int compactIndex = (int)(sample * candidateCount);
            if (compactIndex >= candidateCount) compactIndex = candidateCount - 1;

            return hasValidPrevious && compactIndex >= previousIndex
                ? compactIndex + 1
                : compactIndex;
        }

        private static float SanitizeSample(float sample)
        {
            if (float.IsNaN(sample) || sample <= 0f) return 0f;
            if (sample >= 1f) return 1f;
            return sample;
        }
    }
}
```

- [ ] **Step 2: 在 `Awake` 一次性缓存并压缩有效 Program**

```csharp
protected override void Awake()
{
    base.Awake();
    _health = GetComponent<HealthComponent>();
    _spellCaster = GetComponent<SpellCaster>();
    BuildValidProgramCache();
    _kiteState = new EnemyKiteState(this);
    _rangedAttackState = new EnemyRangedAttackState(this);
}

private void BuildValidProgramCache()
{
    int validCount = 0;
    if (_spellPrograms != null)
    {
        for (int i = 0; i < _spellPrograms.Length; i++)
            if (IsUsableProgram(_spellPrograms[i])) validCount++;
    }

    _validPrograms = new WandLoadout[validCount];
    int write = 0;
    if (_spellPrograms != null)
    {
        for (int i = 0; i < _spellPrograms.Length; i++)
            if (IsUsableProgram(_spellPrograms[i])) _validPrograms[write++] = _spellPrograms[i];
    }

    if (validCount == 0)
        GameLog.Warn("远程敌人没有可执行的 WandLoadout，施法动作不会产出法术", "Enemy");
}

private static bool IsUsableProgram(WandLoadout program)
{
    return program != null && program.Spells != null && program.Spells.Length > 0;
}
```

`new WandLoadout[validCount]` 只在 `Awake` 发生；施法热路径只读紧凑数组。

- [ ] **Step 3: 用统一法术 Runtime 替换 `SpawnFireball`**

```csharp
public bool CastSelectedProgram()
{
    if (_validPrograms == null || _validPrograms.Length == 0 ||
        _spellCaster == null || _castOrigin == null || _health == null)
    {
        GameLog.Warn("远程敌人缺少有效 Program、SpellCaster、CastOrigin 或 HealthComponent", "Enemy");
        return false;
    }

    int selectedIndex = EnemySpellProgramSelector.SelectNextIndex(
        _validPrograms.Length,
        _lastProgramIndex,
        Random.value);
    if (selectedIndex < 0) return false;

    Transform target = Perception.Target;
    Vector3 aimPoint = target != null
        ? target.position + Vector3.up * _aimHeightOffset
        : _castOrigin.position + transform.forward;

    _lastProgramIndex = selectedIndex;
    _spellCaster.CastProgram(
        _validPrograms[selectedIndex],
        _castOrigin.position,
        aimPoint,
        _health.TeamId,
        _health.Id,
        _cc,
        SpellManaPolicy.IgnoreMana);
    return true;
}
```

删除旧 `Instantiate(_definition.ProjectilePrefab)`、`GetComponent<Fireball>()`、手动伤害/速度和 `fireball.Init(...)`。`CastProgram` 的返回值是 EmitCommand 数量，不能被 Enemy 误解为实际生成对象数，因此这里只返回“是否提交了有效 Program”。
