# GPU 液体远近等面积 LOD 修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Water/Poison 在 Near `Marching Cubes` 与 Far 粒子代理之间切换时保持稳定的世界空间占地面积，并让至少 40 米宽的 Resident 区域可见而不扩张昂贵的 Near 三维体素网格。

**Architecture:** 保留现有 GPU PBF、Near `Density + Marching Cubes` 和 Resident Far Draw。Far Vertex Shader 根据粒子 Activity Flag 选择两种基底：已落稳粒子使用世界空间 `XZ` 圆片，远程新生且仍在模拟的液滴使用 Camera-facing Billboard；Fragment Shader 只在圆片最外侧进行可调羽化。40 米需求通过 Resident Far Draw 承担，Near Bounds 仍是独立的局部质量预算。

**Tech Stack:** Unity 6.3、URP 17.3、HLSL、`Graphics.RenderPrimitivesIndirect`、C# `ScriptableObject`、NUnit EditMode Tests。

**Spec:** `docs/superpowers/plans/2026-08-24 GPU液体远景连续性与远程生成修复实施计划.md` 的 Task 40-42，以及 2026-08-24 用户确认的“Near 局部高质量 + Far 40 米稳定可见”修订设计。

## Global Constraints

- 不修改 PBF 粒子位置、速度、碰撞、Gameplay Occupancy 或 Material Semantic。
- 不把 `Maximum Surface Bounds Size` 扩成 `40 × 40 × 40`，避免三维采样成本按体积增长。
- Far Draw 继续使用 `FluidGpuSnapshot.ResidentRenderBounds`，不跟随玩家 Interest Bounds 裁剪。
- 落稳液体的 Far 轮廓必须使用世界空间 `XZ` 基底；Remote Spawn Active 液滴继续使用 Camera-facing 基底。
- 新参数必须进入 `LiquidRenderSettings` 不可变快照，并经过有限值与范围验证。
- Runtime 热路径不得增加托管分配、LINQ、Boxing 或 GPU Readback。
- 不需要新增 Texture、Mesh、VFX、Material 或其他用户提供资源。

## 回滚与 Debug

- 若地面 Far Splat 整体消失，优先检查世界 `XZ` 顶点的 Winding 与 `Cull Back`，不要先增大 Alpha。
- 若地面仍有缺块，先提高 `Far Splat Radius Multiplier`，再降低 `Far Splat Edge Start Ratio`；一次只调整一个变量。
- 若边缘悬浮，降低 `Far Splat Depth Lift`；若仍被地面吃掉，小幅提高它，但保持在粒子半径以内。
- 若空中液滴从侧面消失，检查 `RemoteSpawnActive` 是否仍写入 Metadata，而不是把所有粒子强制改回 Billboard。
- 若 40 米区域仍不可见，检查 `ResidentRenderBounds` 和 Camera Culling/Far Clip；不要扩大 Near `Maximum Surface Bounds Size`。

### Task 45：40 米体积 Mid Surface 与不可见三层 LOD 交接

**用户验收目标：** 玩家周围 40 米以内的 Water/Poison 必须保持三维流体表面，不能退化成水平薄片；只有 40 米以外允许使用低成本 Far Splat。Near/Mid/Far 的交界不得形成浅蓝色亮线、硬裁切圈或可辨认的开发者 LOD 边界。运动、下落中的液体即使暂时没有形成足够密度的 Iso Surface，也不能从侧视角短暂消失。

**Architecture：** 保留单一 GPU PBF Particle Truth 与已有 Near 高精度 `Density + Marching Cubes`；恢复 Planner 已存在但 Runtime 未消费的第二套低精度 3D Grid，将其限定为以玩家活动中心为中心、水平半径 40 米的 Mid Surface。Far Splat 只在 Mid 外部承担可读性。三层权重为 `Near`、`Mid × (1-Near)`、`1-Mid`，交叉带使用互补权重而不是完整 Alpha 叠加；少量未休眠粒子允许使用 Camera-facing 动态安全代理，落稳粒子仅在 40 米外使用 World-XZ Splat。Presentation 参数从 Profile 实时读取，资源尺寸参数仍在初始化时快照化。

**Assets：** 不需要新增 Texture、Material、VFX、Mesh 或其他外部美术资产；复用现有 Water/Poison Material、Density Compute、Marching Cubes Compute、Anisotropy Buffer 与 Procedural Liquid Shader。
