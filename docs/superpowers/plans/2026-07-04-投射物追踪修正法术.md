# 投射物追踪修正法术 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个有限时间、有限转向的投射物追踪 `Modify` 法术，让后续 `Emit` 投射物在检测到敌人后短时间偏向目标，但不会变成必中完全追踪。

**Architecture:** 追踪参数沿现有法术解释器主链路传递：`SpellDefinition -> CastModifierState -> CastEvaluator -> EmitCommand -> SpellCaster -> ProjectileBase`。`Game.Skills` 只保存和烘焙纯数据；`SpellCaster` 负责把 `EmitCommand` 注入真实 projectile；`ProjectileBase` 执行目标扫描和 `Rigidbody.linearVelocity` 有限转向。

**Tech Stack:** Unity 6.3、C#、`ScriptableObject`、`Rigidbody.linearVelocity`、`Physics.OverlapSphereNonAlloc`、`Vector3.RotateTowards`、NUnit EditMode tests。

## Global Constraints

- 不创建 `HomingFireball` 特例 prefab 或专用投射物类。
- 不做完全追踪、不做必中、不做持续到命中为止的导弹。
- 不写 `Assets/_Project/Docs` 解析文档，除非用户另行要求。
- 不创建 `.meta` 文件。
- 不使用 worktree，直接在本地项目修改。
- `Game.Skills` 保持纯逻辑，不引用 Unity 场景对象或物理查询。
- `Game.Combat` 不依赖 `Game.Skills` 或 `Game.Character`。
- 追踪扫描不得使用 `Physics.OverlapSphere`、LINQ、每帧 `new` 数组或 `new List`。
- Unity 编译、Animator、Prefab、Play Mode 测试由用户在 Editor 中执行。

## 你需要在 Unity Editor 中做的事

### Assets / ScriptableObjects

1. 创建或复制一个 `SpellDefinition`。
2. 命名为 `Spell_Mdy_Homing`。
3. 设置：

```text
Kind = Modify
DisplayName = 追踪
Icon = 追踪修正图标
ModDamageAddFlat = 0
ModDamageMul = 1
ModSpeedMul = 1
ModSpreadAddDegrees = 0
ModBounceAdd = 0
ModUseGravity = false
ModHomingRadius = 6
ModHomingDuration = 0.6
ModHomingTurnRateDegrees = 120
ExtraDraws = 0
```

4. 加入 `SpellLibrary.Available`。

### Play Mode verification

测试：

```text
[追踪] [普通火球]
[追踪] [重力] [普通火球]
[追踪] [弹跳] [普通火球]
[追踪] [触发火球] [普通火球]
[追踪] [定时火球] [普通火球]
[追踪] [三重] [火球] [火球] [火球]
```

观察：

- 无敌人在范围内时不转向。
- 有敌人在范围内时短时间偏移，不是瞬间锁头。
- 追踪结束后不继续追踪。
- 角度太偏仍然可能打空。
- Profiler 中追踪扫描不应产生 GC Alloc。
