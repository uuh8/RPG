# 法力资源系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为法师法术编程系统接入自动恢复的 Mana 蓝条，并让所有法术类型都按 `ManaCost` 控制施法频率。

**Architecture:** `ManaComponent` 放在 `Game.Combat`，由 `SpellCaster` 扣费，由 `PlayerManaBar` 显示。`CastEvaluator` 保持纯逻辑，新增当前层 Mana 估算，runtime 采用“先估算、够则扣费、再执行”的方案 A。

**Tech Stack:** Unity 6.3、C#、UGUI `Image.fillAmount`、`ScriptableObject`、asmdef、NUnit EditMode tests。

## Global Constraints

- 不创建 git worktree，直接在本地工作区修改。
- 不写 `Assets/_Project/Docs`。
- 不手动创建 `.meta` 文件。
- 所有 gameplay log 使用 `GameLog`，不直接使用 `Debug.Log`。
- `Game.Skills` 不引用 Unity scene runtime 对象，不持有 `ManaComponent`。
- `Game.UI` 不引用 `Game.Character`。
