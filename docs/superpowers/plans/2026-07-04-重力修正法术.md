# 重力修正法术实现计划

> **给 agentic worker：**执行本计划时使用 `superpowers:executing-plans`。本计划按任务拆分，每个任务都能独立检查。

**目标：**新增一个 `Modify` 法术，让后续发射的投射物启用 Unity 3D 物理重力。

**架构：**重力修正沿现有法术解释器链路传递：`SpellDefinition -> CastModifierState -> CastEvaluator -> EmitCommand -> SpellCaster -> ProjectileBase.Init(useGravity)`。本次只做“是否启用 Unity 重力”的开关，不做自定义重力倍率。

**技术栈：**Unity 6.3、C#、`Rigidbody.useGravity`、`ScriptableObject`、NUnit EditMode tests。

## 全局约束

- 不写 spec。
- 不写 `Assets/_Project/Docs` 解析文档，除非用户另行要求。
- 不创建 `.meta` 文件。

- UI 脚本：法术图标和资产配置由 Editor 完成。

## Task 1：纯规则层加入重力修正状态

- 新增：`CastModifierState.UseGravity : bool`
- 规则：默认 `false`，多个 Modify 中任意一个启用重力，则后续状态为 `true`

```csharp
public readonly bool UseGravity;
```

- [x] 更新构造函数参数：

```csharp
public CastModifierState(float damageAddFlat, float damageMul, float speedMul, float spreadDegrees, int bounceCount, bool useGravity)
```

- [x] 更新 `Default`：

```csharp
public static CastModifierState Default => new CastModifierState(0f, 1f, 1f, 0f, 0, false);
```

- [x] 更新 `Apply`：

```csharp
UseGravity || modify.ModUseGravity
```

- [x] 在 `CastModifierStateTests.cs` 的测试辅助方法里增加参数：

```csharp
bool useGravity = false
```

并设置：

```csharp

```

- [x] 增加测试：

```csharp
[Test]
public void Default_DisablesGravity()
{
    Assert.IsFalse(CastModifierState.Default.UseGravity);
}

[Test]
public void Apply_Gravity_IsEnabledByAnyModifier()
{
    var s = CastModifierState.Default
        .Apply(Modify())
        .Apply(Modify(useGravity: true));

    Assert.IsTrue(s.UseGravity);
}
```

public void GravityModifier_BakesUseGravity_IntoEmit()
{
    Run(1, 999f, Mod(useGravity: true), Emit());
    Assert.AreEqual(1, _out.Count);
    Assert.IsTrue(_out[0].UseGravity);
}

[Test]

{

    Assert.AreEqual(1, _out.Count);
    Assert.IsTrue(_out[0].UseGravity);
    Assert.IsTrue(_out[0].PayloadMods.UseGravity);
}

## Task 3：运行时启用 Rigidbody 重力

**文件：**

- 修改：`Assets/_Project/Scripts/Character/Spells/SpellCaster.cs`

**接口：**

- 消费：`EmitCommand.UseGravity`
- 调用：`ProjectileBase.Init(..., useGravity: cmd.UseGravity)`

步骤：

- [x] 找到当前固定关闭重力的调用：

```csharp
proj.Init(team, attackerId, cmd.Damage, cmd.DamageType, dir * cmd.Speed, casterCollider, useGravity: false);
```

- [x] 改为：

```csharp
proj.Init(team, attackerId, cmd.Damage, cmd.DamageType, dir * cmd.Speed, casterCollider, useGravity: cmd.UseGravity);
```

说明：

- 无重力修正时，`cmd.UseGravity = false`，保持现有直线火球行为。
- 有重力修正时，`cmd.UseGravity = true`，`ProjectileBase.Init` 会设置 `_rb.useGravity = true`。

2. 命名为 `Spell_Mdy_Gravity`。
3. 设置：

```text
Kind = Modify
DisplayName = 重力
Icon = 重力修正图标
ModUseGravity = true
ModDamageAddFlat = 0
ModDamageMul = 1
ModSpeedMul = 1
ModSpreadAddDegrees = 0
ModBounceAdd = 0
ExtraDraws = 0
```

4. 加入 `SpellLibrary.Available`。
5. 测试组合：

```text
[重力] [普通火球]
[重力] [弹跳] [普通火球]
[重力] [触发火球] [普通火球]
[重力] [定时火球] [普通火球]
```

预期：

- 普通火球会按抛物线下坠。
- 没有重力修正的火球仍保持直线。
- 重力 + 弹跳时，弹跳后继续受重力影响。
- 重力 + 定时时，投射物下坠期间仍可按时间触发 payload。
