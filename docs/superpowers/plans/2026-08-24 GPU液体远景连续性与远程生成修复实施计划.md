**Goal:** 消除玩家附近可见的液体 LOD 消失边界，并让远离玩家生成的液体在落地稳定前继续接受重力、PBF 与碰撞。

**Architecture:** Simulation 侧新增 `RemoteSpawnActive` 活动位，把“玩家 Interest 内活动”和“远处新生粒子尚未落稳”统一为 Solver Eligibility，但不唤醒所有 Resident 粒子。Rendering 侧保留 Near Marching Cubes，把不可靠的全局 Far 体素网格替换为直接读取 Alive 粒子的 Camera-facing Soft Splat，并在 Near 边界做互补 Crossfade。

**Tech Stack:** Unity 6.3、C#、HLSL Compute Shader、URP、GraphicsBuffer、Procedural Indirect Draw、NUnit EditMode/GPU focused tests

**Spec:** 用户于 2026-08-24 确认的“Near Marching Cubes + Far Soft Splat + Remote Spawn Simulation Lease”方案。

## Global Constraints

- 不新增外部 Texture、VFX 或 Material Asset；复用现有液体 Material 与 Procedural Shader。
- `Game.Rendering` 只读取 `IFluidGpuSource`，不得写回 Gameplay/Simulation Truth。
- Fixed Tick 与 Rendering 热路径不得产生托管分配、LINQ、Closure 或 Boxing。
