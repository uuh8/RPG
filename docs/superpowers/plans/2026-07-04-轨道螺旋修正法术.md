# 轨道螺旋修正法术 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个 `Modify` 类法术，让后续投射物围绕“看不见的移动圆心”旋转前进，形成可覆盖 3D 空间的轨道/螺旋弹道。

**Architecture:** `Game.Skills` 只负责纯数据求值：把轨道半径、角速度、相位快照进 `EmitCommand`。`Game.Character.SpellCaster` 负责把每一发的批次相位注入 `ProjectileBase`。`Game.Combat.ProjectileBase` 负责实际飞行控制：在 `FixedUpdate()` 中推进移动圆心，并用 `Rigidbody.linearVelocity` 把投射物推向圆心周围的目标轨道点。

**Tech Stack:** Unity 6.3, C#, `ScriptableObject`, `readonly struct`, NUnit EditMode tests, `Rigidbody.linearVelocity`, `FixedUpdate()`, `Quaternion.LookRotation`, `Mathf.Sin/Cos`, `Vector3.Dot`, `Vector3.Reflect`

- 轨道与追踪同时存在时，MVP 规则为：轨道优先，启用轨道的投射物不执行 homing 转向。
- 轨道与弹跳同时存在时，MVP 规则为：发生环境 bounce 后关闭轨道，投射物按反射方向继续飞。
- 轨道与重力同时存在时，MVP 规则为：轨道控制优先；`Rigidbody.useGravity` 可保持配置值，但轨道每个 `FixedUpdate()` 写入的速度会主导运动。

```csharp
[Test]
public void Apply_Orbit_UsesMaxRadiusAddsAngularSpeedAndPhaseOffsetAndUsesMaxAbsPlaneTilt()
{
    var s = CastModifierState.Default
        .Apply(Modify(orbitRadius: 0.6f, orbitAngularSpeed: 180f, orbitPhaseOffset: 15f, orbitPlaneTilt: 25f))
        .Apply(Modify(orbitRadius: 1.0f, orbitAngularSpeed: 90f, orbitPhaseOffset: 30f, orbitPlaneTilt: -35f));

    Assert.AreEqual(1.0f, s.OrbitRadius, 1e-4f);
    Assert.AreEqual(270f, s.OrbitAngularSpeedDegrees, 1e-4f);
    Assert.AreEqual(45f, s.OrbitPhaseOffsetDegrees, 1e-4f);
    Assert.AreEqual(-35f, s.OrbitPlaneTiltDegrees, 1e-4f);
}
```

规则解释：

- `OrbitRadius` 用 `max`，避免多个轨道修正叠加后半径失控。
- `OrbitAngularSpeedDegrees` additive，允许多个旋转修正叠加成更快旋转，也允许负值抵消。
- `OrbitPhaseOffsetDegrees` additive，用于整体旋转起始角。
- `OrbitPlaneTiltDegrees` 使用绝对值更大的那个值，用于避免多颗投射物轨道面重合。

```csharp
/// <summary>

}
```

- [ ] **Step 6: 在 `SpellAiming.cs` 增加轨道面错开函数**

```csharp
/// <summary>
/// 给同批轨道投射物分配不同旋转平面。index 0 保持 0，后续按 +base/-base/+2base/-2base 交替。
/// </summary>
public static float PlaneTiltDegrees(int index, int count, float baseTiltDegrees)
{
    if (count <= 1 || Mathf.Approximately(baseTiltDegrees, 0f)) return 0f;
    if (index <= 0) return 0f;

    int ring = (index + 1) / 2;
    float sign = index % 2 == 1 ? 1f : -1f;
    return sign * ring * baseTiltDegrees;
}
```

- [ ] **Step 2: 增加 `ConfigureOrbit(...)` 方法**

放在 `ConfigureHoming(...)` 后：

```csharp
/// <summary>配置本次投射物的轨道螺旋运动。由 SpellCaster 从 EmitCommand 注入。</summary>
public void ConfigureOrbit(float radius, float angularSpeedDegrees, float phaseOffsetDegrees, float planeTiltDegrees)
{
    _orbitRadius = Mathf.Max(0f, radius);
    _orbitAngularSpeedDegrees = angularSpeedDegrees;
    _orbitAngleDegrees = phaseOffsetDegrees;
    _orbitPlaneTiltDegrees = planeTiltDegrees;
    _orbitEnabled = _orbitRadius > 0f && !Mathf.Approximately(_orbitAngularSpeedDegrees, 0f);
    _orbitCenter = Vector3.zero;
    _orbitForward = Vector3.forward;
    _orbitRight = Vector3.right;
    _orbitUp = Vector3.up;
    _orbitCenterSpeed = 0f;
```

- [ ] **Step 4: 增加 `InitializeOrbit(...)` 方法**

放在 `ConfigureOrbit(...)` 后或 `TickOrbit(...)` 前：

```csharp
private void InitializeOrbit(Vector3 velocity)
{
    Vector3 forward = velocity.sqrMagnitude > 1e-6f ? velocity.normalized : transform.forward;
    if (forward.sqrMagnitude <= 1e-6f)
        forward = Vector3.forward;

    _orbitForward = forward.normalized;
    _orbitCenter = transform.position;
    _orbitCenterSpeed = velocity.magnitude;

    Vector3 upSeed = Mathf.Abs(Vector3.Dot(_orbitForward, Vector3.up)) > 0.95f
        ? Vector3.forward
        : Vector3.up;

    Quaternion basis = Quaternion.LookRotation(_orbitForward, upSeed);
    if (!Mathf.Approximately(_orbitPlaneTiltDegrees, 0f))
        basis = Quaternion.AngleAxis(_orbitPlaneTiltDegrees, basis * Vector3.right) * basis;
    _orbitRight = basis * Vector3.right;
    _orbitUp = basis * Vector3.up;
}
```

关键点：

- `upSeed` 避免发射方向接近世界 `Vector3.up` 时，轨道坐标系退化。
- `_orbitCenter = transform.position` 表示圆心从出膛点开始前进。
- 第一帧的投射物位置会被速度拉向 `center + offset`，形成轨道半径。

- [ ] **Step 6: 增加 `TickOrbit(...)` 方法**

```csharp
private void TickOrbit(float deltaTime)
{
    if (!_orbitEnabled || _rb == null)
        return;

    float safeDeltaTime = Mathf.Max(deltaTime, 1e-5f);
    _orbitCenter += _orbitForward * _orbitCenterSpeed * safeDeltaTime;
    _orbitAngleDegrees += _orbitAngularSpeedDegrees * safeDeltaTime;

    float radians = _orbitAngleDegrees * Mathf.Deg2Rad;
    Vector3 offset = (_orbitRight * Mathf.Cos(radians) + _orbitUp * Mathf.Sin(radians)) * _orbitRadius;
    Vector3 targetPosition = _orbitCenter + offset;
    Vector3 newVelocity = (targetPosition - _rb.position) / safeDeltaTime;

    _rb.linearVelocity = newVelocity;
    _launchVelocity = newVelocity;
    _currentSpeed = newVelocity.magnitude;
}
```

为什么用 `linearVelocity` 而不是直接改 `position`：

- 保持 `Rigidbody` 参与物理碰撞。
- 高速碰撞仍能依赖 `ContinuousDynamic`。
- 不需要把 `ProjectileBase` 从物理系统中剥离出来。

## Implementation Notes

这个功能的关键不在 `Multicast`，而在“每一发 projectile 拥有独立相位，但共享同一类运动规则”。`三重射击` 只负责让本次 cast 产生三条 `EmitCommand`，`轨道螺旋` 负责改变这些 `EmitCommand` 后续生成的 projectile 的飞行控制方式。

数学模型保持简单：

```text
center += forward * centerSpeed * fixedDeltaTime
angle += angularSpeed * fixedDeltaTime
offset = (right * cos(angle) + up * sin(angle)) * radius
targetPosition = center + offset
velocity = (targetPosition - currentPosition) / fixedDeltaTime
```

这个实现的取舍是：

- 优点：稳定、可控、参数少，适合做成 `Modify` 法术。
- 优点：不依赖 `AddForce`，不同帧率下更容易预测。
- 优点：保留 `Rigidbody` 碰撞，不破坏现有 `ProjectileBase -> IDamageable` 战斗漏斗。
- 代价：这不是真实物理模拟，而是 kinematic-style 的 velocity controller。
- 代价：和 homing 都属于“主运动控制器”，MVP 阶段必须定义优先级，不能同时争夺 velocity。
