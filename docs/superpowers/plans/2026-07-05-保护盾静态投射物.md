# 保护盾静态投射物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增一个普通 `StaticProjectile` 法术“保护盾”：释放时在当前施法点生成，作为触发 payload 时在命中点生成；它能反弹玩家和敌方投射物，反弹后的投射物归属护盾释放者，反弹次数耗尽后护盾立刻销毁。

**Architecture:** `Game.Skills` 只扩展纯数据和解释器快照；`Game.Character.SpellCaster` 只负责按 `EmitCommand.SpawnMode` 在正确位置生成静态物并注入初始化数据；`Game.Combat.ProjectileShield` 负责 Trigger 检测和反弹规则，`ProjectileBase` 提供被护盾反弹的公开接口。保护盾作为普通 `StaticProjectile` 进入现有 `payload` 和 `CastModifierState` 链路，不做硬编码技能分支。

**Tech Stack:** Unity 6.3、C#、`ScriptableObject`、`Rigidbody.linearVelocity`、`SphereCollider.isTrigger`、`Vector3.Reflect`、NUnit EditMode tests、`dotnet build` 编译验证。

## Global Constraints

- 直接在本地工作区修改，不创建 git worktree。
- 不手动创建 `.meta` 文件。
- 不写 `Assets/_Project/Docs`。
- `Game.Skills` 保持纯逻辑，不引用 scene object，不直接实例化。
- `Game.Combat` 不依赖 `Game.Skills` / `Game.Character`。
- `SpellCaster` 只做 runtime 桥接，不承担反弹物理计算。
- 使用 `GameLog`，不直接使用 `Debug.Log`。
- 保护盾必须是普通 `SpellKind.StaticProjectile`：直接释放在当前释放点生成，被触发 payload 释放时在命中点生成。
- 玩家和敌方投射物都会被反弹；被反弹投射物统一改成护盾释放者阵营和攻击者归属。
- 反弹次数耗尽后护盾立刻销毁。

### Task 2: 扩展 ProjectileBase 的护盾反弹接口

**Files:**
- Modify: `Assets/_Project/Scripts/Combat/Projectiles/ProjectileBase.cs`

**Interfaces:**
- Produces: `public bool ReflectByShield(Vector3 shieldNormal, byte newTeam, int newAttackerId)`
- Consumes: current `Rigidbody.linearVelocity`
- Updates: `_attackerTeam`, `_attackerId`, `_launchVelocity`, `_currentSpeed`

**为什么在 ProjectileBase 里做反弹：**

护盾只知道“我要把这个投射物按某个法线反弹”。但具体投射物内部有 `Rigidbody`、`_launchVelocity`、`_currentSpeed`、追踪/轨道运动状态、阵营过滤缓存。让护盾直接改这些 private 字段会破坏封装，所以应该由 `ProjectileBase` 暴露一个小而明确的接口。

- [ ] **Step 1: 在 `ProjectileBase` 添加公开方法骨架**

在 `Assets/_Project/Scripts/Combat/Projectiles/ProjectileBase.cs` 中，建议放在 `ConfigureOrbit` 后、`ArmTimedTrigger` 前：

```csharp
public bool ReflectByShield(Vector3 shieldNormal, byte newTeam, int newAttackerId)
{
    if (_consumed || _rb == null)
        return false;

    Vector3 velocity = _rb.linearVelocity;
    if (velocity.sqrMagnitude <= 1e-6f)
        return false;

    Vector3 normal = shieldNormal.sqrMagnitude > 1e-6f ? shieldNormal.normalized : -velocity.normalized;
    Vector3 incoming = velocity.normalized;
    Vector3 reflected = Vector3.Reflect(incoming, normal);
    if (reflected.sqrMagnitude <= 1e-6f)
        return false;

    reflected.Normalize();
    float speed = velocity.magnitude;
    Vector3 newVelocity = reflected * speed;

    _attackerTeam = newTeam;
    _attackerId = newAttackerId;
    _orbitEnabled = false;
    _rb.linearVelocity = newVelocity;
    _launchVelocity = newVelocity;
    _currentSpeed = speed;

    if (reflected.sqrMagnitude > 1e-6f)
        transform.rotation = Quaternion.LookRotation(reflected) * Quaternion.Euler(_modelForwardOffsetEuler);

    return true;
}
```

注意：反弹时禁用 `_orbitEnabled`，否则轨道运动下一帧会重新接管速度，看起来像“没被反弹”。追踪是否禁用可以先不动，因为追踪下一帧可能继续转向敌人；如果测试中表现不清晰，再考虑同时清理 homing 状态。

### Task 3: 新增 ProjectileShield

**Files:**
- Create: `Assets/_Project/Scripts/Combat/Projectiles/ProjectileShield.cs`
- If needed for local dotnet build: Modify `Game.Combat.csproj`

**Interfaces:**
- Produces: `public void Init(byte ownerTeam, int ownerAttackerId, int reflectCount, Collider ownerCollider)`
- Consumes: `ProjectileBase.ReflectByShield(Vector3, byte, int)`

**核心逻辑：**

护盾是一个 `Trigger` 交互体。它自己不继承 `ProjectileBase`，因为它不会飞行、不会造成直接伤害、不会走命中销毁逻辑。它只负责反弹进入范围的投射物。

- [ ] **Step 1: 创建 `ProjectileShield.cs`**

新增文件 `Assets/_Project/Scripts/Combat/Projectiles/ProjectileShield.cs`：

```csharp
using UnityEngine;
using Game.Core;

namespace Game.Combat
{
    [RequireComponent(typeof(Collider))]
    public class ProjectileShield : MonoBehaviour
    {
        [SerializeField, Min(0)] private int _fallbackReflectCount = 3;

        private Collider _shieldCollider;
        private Collider _ownerCollider;
        private byte _ownerTeam;
        private int _ownerAttackerId;
        private int _reflectRemaining;
        private bool _initialized;

        private void Awake()
        {
            _shieldCollider = GetComponent<Collider>();
            if (_shieldCollider != null && !_shieldCollider.isTrigger)
                GameLog.Warn("ProjectileShield 的 Collider 建议设置 Is Trigger=true，否则可能无法正确接管投射物反弹", "Combat");
        }

        public void Init(byte ownerTeam, int ownerAttackerId, int reflectCount, Collider ownerCollider)
        {
            _ownerTeam = ownerTeam;
            _ownerAttackerId = ownerAttackerId;
            _ownerCollider = ownerCollider;
            _reflectRemaining = Mathf.Max(0, reflectCount);
            _initialized = true;

            if (_shieldCollider != null && _ownerCollider != null)
                Physics.IgnoreCollision(_shieldCollider, _ownerCollider);

            if (_reflectRemaining <= 0)
                Destroy(gameObject);
        }

        private void OnTriggerEnter(Collider other)
        {
            if (!_initialized)
            {
                Init(_ownerTeam, _ownerAttackerId, _fallbackReflectCount, _ownerCollider);
            }

            if (_reflectRemaining <= 0 || other == null)
                return;

            ProjectileBase projectile = other.GetComponentInParent<ProjectileBase>();
            if (projectile == null)
                return;

            Vector3 normal = other.transform.position - transform.position;
            if (normal.sqrMagnitude <= 1e-6f)
                normal = other.bounds.center - transform.position;
            if (normal.sqrMagnitude <= 1e-6f)
                normal = transform.forward;

            if (!projectile.ReflectByShield(normal, _ownerTeam, _ownerAttackerId))
                return;

            _reflectRemaining--;
            if (_reflectRemaining <= 0)
                Destroy(gameObject);
        }
    }
}
```

说明：

- `fallbackReflectCount` 是 Prefab 被手动放进场景时的兜底值。
- runtime 从法术生成时会调用 `Init(...)` 覆盖它。
- `Physics.IgnoreCollision(_shieldCollider, _ownerCollider)` 防止护盾 Trigger 干扰释放者自身。

**关键理解：**

- 直接施法时，`spawnPos` 是玩家法杖释放点。
- OnImpact payload 时，`spawnPos` 是命中点。

这正是“护盾作为普通静态投射物”的核心。

- [ ] **Step 2: 新增 `SpawnStaticProjectileAtPoint`**

在 `SpellCaster` 中新增方法，建议放在 `SpawnForwardProjectile` 后：

```csharp
private void SpawnStaticProjectileAtPoint(EmitCommand cmd, Vector3 spawnPos, Vector3 baseDir,
                                          byte team, int attackerId, Collider casterCollider)
{
    if (cmd.ProjectilePrefab == null)
    {
        GameLog.Warn("StaticAtPoint 的 ProjectilePrefab 为空，无法生成静态投射物", "Skills");
        return;
    }

    Quaternion rotation = cmd.ProjectilePrefab.transform.rotation;
    if (baseDir.sqrMagnitude > 1e-6f)
        rotation = Quaternion.LookRotation(baseDir.normalized) * rotation;

    GameObject go = Object.Instantiate(cmd.ProjectilePrefab, spawnPos, rotation);
    ProjectileShield shield = go.GetComponent<ProjectileShield>();
    if (shield != null)
    {
        shield.Init(team, attackerId, cmd.ShieldReflectCount, casterCollider);
        return;
    }

    GameLog.Warn($"StaticAtPoint 预制体 {cmd.ProjectilePrefab.name} 上没有 ProjectileShield 组件", "Skills");
}
```

设计说明：

- 这里先只支持 `ProjectileShield`。未来如果有其他原地静态物，可以抽象 `IStaticProjectileRuntime`，但现在不提前抽象。
- 直接用 `spawnPos`，确保 payload 命中点生成。
- 不调用 `ProjectileBase.Init`，因为护盾本身不是飞行投射物。

## Unity Editor 配置清单

### 1. Assets / ScriptableObjects

- [ ] 新建或复制一个 `SpellDefinition`，命名建议：

```text
Spell_Static_Shield
```

- [ ] Inspector 配置：

```text
Kind = StaticProjectile
Display Name = 保护盾
Icon = 你的保护盾图标
Mana Cost = 例如 30
Projectile Prefab = 保护盾 Prefab
Spawn Mode = StaticAtPoint
Shield Reflect Count = 例如 3
```

- [ ] 把 `Spell_Static_Shield` 加入 `SpellLibrary`，否则 Wand Editor 里看不到。

### 2. Prefabs / Components

保护盾 Prefab 必须满足：

```text
有球形视觉体
有 SphereCollider
SphereCollider Is Trigger = true
挂 ProjectileShield
不需要 ProjectileBase
不需要 Rigidbody
```

如果 Prefab 上已有 `Rigidbody`，建议先移除。护盾不靠物理运动，它只接收 Trigger。

### 3. Inspector fields

在 `ProjectileShield` 上：

```text
Fallback Reflect Count = 3
```

这个值只是 Prefab 手动放进场景时的兜底。法术生成时会由 `Spell_Static_Shield.ShieldReflectCount` 覆盖。

### 4. Animator

本功能不需要改 Animator。

### 5. UI / Canvas

只需要给法术配置 Icon。Wand Editor 会按现有 `SpellDefinition.Icon` 显示。

### 6. Scene objects

不需要在场景里预放护盾。护盾由 `SpellCaster` runtime `Instantiate`。

### 7. Play Mode verification

按这个顺序测：

1. 把 `保护盾` 单独放进法杖，释放后确认护盾在玩家释放点生成。
2. 用玩家火球打护盾，确认火球被球面反弹。
3. 确认反弹后的玩家火球不会伤害玩家自己。
4. 让敌人火球打护盾，确认敌方火球被反弹。
5. 确认敌方火球被反弹后能伤害敌人。
6. 设置 `Shield Reflect Count = 1`，确认反弹一次后护盾立刻销毁。
7. 配置：

```text
触发火球 -> 保护盾
```

确认触发火球命中后，护盾在命中点生成，而不是玩家位置生成。

8. 配置：

```text
三重射击 -> 触发火球 -> 保护盾
```

确认多个触发火球命中不同位置时，护盾可以在对应命中点生成。

### 8. Common failure symptoms

| 现象 | 可能原因 |
|---|---|
 护盾生成了，但火球直接爆炸 | 护盾 Collider 没设 `Is Trigger`，导致投射物走普通 `OnCollisionEnter` |
 护盾没有反弹任何东西 | Prefab 没挂 `ProjectileShield`，或 Collider 半径太小 |
 敌方火球反弹后不伤敌 | `ProjectileBase.ReflectByShield` 没改写 `_attackerTeam` / `_attackerId` |
 反弹方向很怪 | normal 计算错，应该使用“护盾球心 -> 投射物位置” |
 护盾永远不消失 | `ShieldReflectCount` 没传入 `ProjectileShield.Init`，或反弹后没扣次数 |
 触发火球后护盾出现在玩家身边 | `SpellCaster` 没使用 payload 的 `hitPoint` 作为 `spawnPos`，或把护盾写成特殊技能 |
